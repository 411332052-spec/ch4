# Discord Server 設定步驟

這份文件帶你做三件事：

1. 建立一個你自己的 Discord Server
2. 建立給 agent 用的頻道，並拿到它的 `CHANNEL_ID`
3. 產生邀請連結，讓同組同學加入你的 Server（後面測試要用）

做完這份，再做 `docs/discord-bot-setup.md`（建立 bot、拿 token、把 bot 邀進來）。

> **適用環境**：Windows 電腦，用 Discord 桌面版或網頁版（discord.com/app）。
> Discord 偶爾會改畫面，如果某個按鈕的位置或字樣和下面寫的稍有不同，請找名稱最接近的選項。
> 下面用「**粗體**」標示畫面上要點的字。

**名詞先解釋**

- **Server（伺服器）**：Discord 裡一個專屬的聊天空間，像一棟大樓。你是擁有者。
- **頻道（Channel）**：Server 裡的一個房間。agent 只會聽你指定的那一個頻道。
- **CHANNEL_ID**：這個頻道的一串數字編號（例如 `123456789012345678`）。agent 靠它知道要聽哪個房間。它不是機密。

---

## 一、建立你自己的 Server

1. 打開 Discord，登入你的帳號。
2. 看畫面**最左邊那一長條**（一排圓形圖示），拉到最下面，找到一個**綠色的「＋」**（滑鼠移上去會顯示「新增伺服器」／Add a Server），點它。
3. 跳出視窗後，點最上面的 **「親自創建」**（Create My Own）。
4. 下一個畫面問你這個 Server 是給誰用的，點 **「僅供我和我的朋友使用」**（For me and my friends）。
5. 在「伺服器名稱」欄位輸入名稱，例如 `食物記錄測試`。
6. 點右下角的 **「創建」**（Create）。
7. 完成後，你會看到新 Server 出現在最左邊那一長條，畫面中間預設已經有一個 `#一般`（general）頻道。

---

## 二、建立給 agent 用的頻道

1. 在畫面**左邊第二欄**（Server 名稱下面那一欄），找到「**文字頻道**」（Text Channels）這幾個字。
2. 把滑鼠移到「文字頻道」那一行的最右邊，會出現一個 **「＋」**，點它。
3. 跳出「創建頻道」視窗：
   - 頻道類型：選 **「文字」**（Text）。
   - 頻道名稱：輸入 `food-log`（名稱只能小寫英文、數字、減號）。
   - **「私人頻道」（Private Channel）開關保持關閉**。（這個頻道你要讓同學看得到才能測試。）
4. 點右下角的 **「創建頻道」**（Create Channel）。
5. 左邊的頻道清單會多出 `# food-log`，點它進去，之後所有測試都在這裡傳照片。

> **為什麼要專用一個頻道**：agent 每處理一張照片就會用掉你自己的 Claude 額度。只讓它聽這一個頻道，其他頻道聊什麼都不會花你的額度。誰能在這個頻道發言，就等於誰能花你的額度，所以只邀請你信任的人（見架構文件第 13 節）。

---

## 三、拿到 CHANNEL_ID

要先打開「開發者模式」，Discord 才會在右鍵選單裡出現「複製頻道 ID」。

### 3-1. 打開開發者模式

1. 看畫面**左下角**，你的頭像和名稱旁邊有一個**齒輪圖示**（使用者設定／User Settings），點它。
2. 在左邊的設定清單往下找到 **「進階」**（Advanced），點它。（在新版畫面裡它可能在「應用程式設定」（App Settings）分類底下。）
3. 找到 **「開發者模式」**（Developer Mode），把右邊的開關**打開**（變成綠色）。
4. 按右上角的 **「ESC」**（或圓形的 X）關掉設定畫面。

### 3-2. 複製頻道 ID

1. 在左邊頻道清單，對 `# food-log` 按**滑鼠右鍵**。
2. 在選單最下面附近，點 **「複製頻道 ID」**（Copy Channel ID）。
3. 打開記事本（或任何文字編輯器），按 **Ctrl + V** 貼上。你會看到一串 17～19 位數字，這就是 `CHANNEL_ID`。
4. 把這串數字暫時留在記事本裡，之後寫 `.env` 設定檔時會用到。**記得不要把這個記事本存在 `C:\Users\Penny\ch4` 專案資料夾裡面。**

> **小提醒**：如果右鍵選單裡找不到「複製頻道 ID」，代表開發者模式沒打開，回到 3-1 檢查。

## 四、產生邀請連結，讓同組同學加入

> **兩種邀請不要搞混**：
> - 這一節的連結是邀請「**人**」（同學）。
> - `docs/discord-bot-setup.md` 裡的連結是邀請「**bot**」。兩者不一樣，不能互相取代。

1. 對左邊的 `# food-log` 頻道按**滑鼠右鍵**，點 **「邀請他人」**（Invite People）。
   （也可以對最左邊的 Server 圖示按右鍵，再點「邀請他人」，效果一樣。）
2. 跳出邀請視窗，**先不要急著複製**。看視窗右下角（或「邀請連結」那一列旁邊）有一個**齒輪圖示**，點它，進入「編輯邀請連結」（Edit invite link）。
3. 設定這兩項，避免連結被轉傳到不該進來的人手上：
   - **「到期時間」**（Expire After）：選 **「7 天」**（或更短，例如 1 天）。
   - **「最大使用次數」**（Max number of uses）：選你同組同學的人數，例如 **「5 次使用」**（Discord 提供的選項有固定幾檔，選等於或略多於人數的那一檔）。
   - **「授予臨時成員資格」**（Grant temporary membership）：保持**關閉**。
4. 點 **「產生新連結」**（Generate a New Link）。
5. 回到邀請視窗，網址欄會顯示新的連結（長得像 `https://discord.gg/xxxxxxx`），點右邊的 **「複製」**（Copy）。
6. 把這個連結傳給同組同學（例如貼到你們的 LINE 群組）。
7. 同學點開連結 → 登入 Discord → 點 **「接受邀請」**（Accept Invite），就進到你的 Server 了。

### 測試完之後（建議做）

1. 對 Server 名稱按右鍵 → **「伺服器設定」**（Server Settings） → 左邊找 **「邀請」**（Invites）。
2. 在清單裡找到剛才那個連結，點右邊的 **「X」**（撤銷／Revoke）刪除它。連結就不能再被使用，已經進來的人不受影響。
